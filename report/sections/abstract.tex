\begin{abstract}
Grounded drug question answering must retrieve the right evidence and avoid unsupported answers, yet Vietnamese lacks the resources to evaluate either. We build a Vietnamese drug-information corpus from the national formulary and package leaflets, a 10{,}000-question retrieval benchmark whose answer locations are known by construction, and a 500-item end-to-end set covering single-turn, multi-turn, unanswerable, out-of-scope and prompt-injection requests. Hybrid retrieval with reranking places a correct passage in the top ten for 97.7\% of benchmark questions. On top of it, we design an agentic RAG pipeline that keeps the control flow in code and asks the language model only for small structured decisions. The pipeline cuts hallucinated answers twelvefold for a hosted model and eightfold for the open-weight Qwen3.5-9B. Inside the pipeline, this 9-billion-parameter model outperforms the hosted model answering alone (truthfulness 0.77 against 0.27), reaches 92\% of the hosted pipeline's nugget recall and matches its severe-harm rate, showing that the harness and the data, not model scale, carry most of the accuracy. Ablations trace the agentic gain to a single query-rephrasing step, which answers every multi-turn follow-up that single-step RAG leaves 96\% unanswered, whereas an iterative judge--refine loop adds cost without measurable benefit.
