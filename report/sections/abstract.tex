\begin{abstract}
Grounded drug question answering requires both retrieving the appropriate evidence and avoiding unsupported answers, yet Vietnamese lacks dedicated resources for evaluating these capabilities. We construct a Vietnamese drug-information corpus from the national drug formulary and package leaflets, together with a 10{,}000-question retrieval benchmark whose answer locations are known by construction and a 500-item end-to-end evaluation set covering single-turn, multi-turn, unanswerable, out-of-scope, and prompt-injection requests. On the retrieval benchmark, hybrid retrieval followed by reranking performs best and places a correct passage in the top ten for 97.7\% of questions. On top of this retriever, we design an agentic retrieval-augmented generation pipeline that keeps its control flow in code and asks the language model only for small structured decisions, so that it runs on low-cost language models. Compared with the same models answering without retrieval, the pipeline cuts hallucinated answers twelvefold with a hosted model (from 18.3\% to 1.5\%) and eightfold with a 9-billion-parameter open-weight model (from 30.6\% to 3.7\%), whose nugget recall rises from 0.24 to 0.86. It also answers every multi-turn follow-up question, of which single-step RAG leaves 96\% unanswered, and it declines every unanswerable request. Beyond providing, to our knowledge, the first dedicated benchmark for Vietnamese drug-information retrieval, our ablations reveal that the benefit of agentic control comes from a single query-rephrasing step, whereas an iterative judge--refine loop adds cost without a measurable gain in answer quality.
