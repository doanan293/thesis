\begin{abstract}
Answering questions about medicines requires accurate, well-grounded answers, yet Vietnamese lacks benchmarks for drug information retrieval, and many deployments can only afford inexpensive language models. We build a corpus of 3{,}120 documents from the Vietnamese National Drug Formulary and drug package leaflets, with deterministic enrichment, and a 10{,}000-question retrieval benchmark with known answer locations. Through the production retrieval code we compare BM25, five dense embedding models, hybrid reciprocal rank fusion and four rerankers, reporting quality next to cost: fusing Qwen3-Embedding-4B with BM25 and reranking with Qwen3-Reranker-4B gives the best ranking (97.5\% Hit@10, 0.859 nDCG@10). On top of this retriever we build an agentic RAG pipeline in which low-cost LLMs make only small structured decisions, and evaluate it on a 500-item golden set with CRAG-style truthfulness, nugget recall, citation, refusal and prompt-injection metrics, paired ablations and a calibrated LLM judge. \pending{E2E headline: full vs one-step truthfulness, significant ablations, injection defence}. The corpus construction, benchmark and evaluation protocol offer a reproducible basis for Vietnamese medical RAG.

\end{abstract}
