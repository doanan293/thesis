\begin{abstract}
Answering drug questions demands accurate, grounded evidence, yet Vietnamese has no resource to evaluate it. We build a Vietnamese drug-information corpus from the national formulary and package leaflets, a 10{,}000-question retrieval benchmark with answer locations known by construction, and a 500-item end-to-end set spanning single-turn, multi-turn, unanswerable, out-of-scope and prompt-injection requests. Hybrid retrieval with reranking finds a correct passage in the top ten for 97.7\% of questions. On top of it, we design an agentic RAG architecture that maximises answer accuracy and suppresses hallucination. With Gemini 3.8 Flash and with the open-weight Qwen3.5-9B, it cuts hallucinated answers twelvefold and eightfold. With this architecture, the 9B model far surpasses Gemini answering alone (truthfulness 0.77 against 0.27) and comes close to Gemini with the same architecture (nugget recall 0.86 against 0.93). The harness and the data, not model scale, carry the accuracy. Ablations trace the agentic gain to query rephrasing, which answers every multi-turn follow-up that single-step RAG leaves 96\% unanswered, while an iterative judge--refine loop adds cost without gain.

\end{abstract}
