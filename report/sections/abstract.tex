\begin{abstract}
Grounded drug question answering must retrieve the right evidence and avoid unsupported answers, yet Vietnamese lacks the resources to evaluate either. We build a Vietnamese drug-information corpus from the national formulary and package leaflets, a 10{,}000-question retrieval benchmark whose answer locations are known by construction, and a 500-item end-to-end set covering single-turn, multi-turn, unanswerable, out-of-scope and prompt-injection requests. Hybrid retrieval with reranking places a correct passage in the top ten for 97.7\% of benchmark questions. On top of it, we design an agentic RAG pipeline that keeps the control flow in code and asks the language model only for small structured decisions. We run the pipeline with the hosted Gemini 3.8 Flash and with the open-weight Qwen3.5-9B, and it cuts hallucinated answers twelvefold and eightfold, respectively, against the same models answering without retrieval. With the pipeline, the 9-billion-parameter model clearly surpasses Gemini answering on its own (truthfulness 0.77 against 0.27) and comes close to Gemini with the same pipeline (nugget recall 0.86 against 0.93). The harness and the data, not model scale, thus carry most of the accuracy, and a small open-weight model is a viable choice for deployment. Ablations trace the agentic gain to a single query-rephrasing step, which answers every multi-turn follow-up that single-step RAG leaves 96\% unanswered, whereas an iterative judge--refine loop adds cost without measurable benefit.
