\begin{abstract}
Answering questions about medicines requires accurate answers that are grounded in authoritative sources. For Vietnamese, this task lacks evaluation resources, and practical systems often have to rely on low-cost language models. This paper makes three contributions. First, we build a Vietnamese drug-information corpus from the national drug formulary and package leaflets, together with a 10{,}000-question retrieval benchmark whose answer locations are known by construction. Second, we compare sparse, dense, hybrid and reranked retrieval on this benchmark and report effectiveness together with deployment cost. Third, we design an agentic retrieval-augmented generation pipeline that keeps its control flow in code and asks the language model only for small structured decisions, so that a small open-weight model can run it. We evaluate the pipeline with a hosted model and with the 9-billion-parameter Qwen3.5-9B on a 500-item golden set with established correctness, attribution and safety metrics, paired ablations and a calibrated automatic judge. Hybrid retrieval followed by reranking achieves the best ranking quality, with 97.5\% Hit@10 and an nDCG@10 of 0.859. \pending{E2E headline finding}

\end{abstract}
