\section{Conclusion}\label{sec:conclusion}

This paper built a Vietnamese drug-information corpus, a 10{,}000-question retrieval benchmark with known answer locations, and an agentic RAG pipeline in which every model call is a single small decision. Hybrid fusion followed by reranking gives the best ranking quality at a cost that a 4B reranker keeps moderate. End to end, grounding is what makes the answers usable, cutting hallucinated answers from 18.3\% to 1.5\% with a API model and from 30.6\% to 3.7\% with a 9-billion-parameter open-weight model. Query rephrasing lets the pipeline answer every conversational follow-up question, whereas the judge--refine loop added cost without a measurable gain, so a small open-weight model with a self-hosted retriever is a viable deployment when the budget excludes API models.

Several limitations bound these conclusions. The benchmark questions are generated by rules, so they are more regular than patient questions, and the fusion constant and the reranker instruction were selected on the same benchmark. The golden set was written by a language model without pharmacist review, and the automatic judge shares a provider with the API answer model, a risk that calibration measures but cannot remove. A cheaper remedy for follow-up questions than rephrasing, such as appending the previous turns to the search query, was not tested, and the leaflets come from a single online source.

Future work should add pharmacist review of a subset, questions from real users, and a check for answers that mix information about different drugs.
